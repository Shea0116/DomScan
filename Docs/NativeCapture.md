# 原生控件与区域截图

DomScan 提供三种独立标注的采集来源。HTML 接口可用时读取 DOM；没有 HTML 接口时，可以选择辅助功能控件或手动框选截图。原生采集不要求目标应用重启或接入开发桥接。

| 来源 | 可以采集 | 不提供 |
| --- | --- | --- |
| DOM | HTML、文本、计算样式、CSS 像素尺寸、frame 路径 | 源码文件与行号 |
| macOS 辅助功能 | 控件角色、名称、说明、标识符、屏幕位置与尺寸 | DOM、CSS、源码映射、输入框当前值；定位描述也不保证唯一 |
| 区域截图 | 选定窗口内区域的 PNG 图像及屏幕位置 | DOM、CSS、OCR 文本、源码映射 |

## 点选原生控件

1. 从 DomScan 选择正在运行的目标应用。
2. 点击当前采集区的 **“其他采集方式 → 点选原生控件（辅助功能）”**，或使用接入提示里的同名按钮。
3. 首次使用时，在 **系统设置 → 隐私与安全性 → 辅助功能** 中允许 DomScan，然后重新点击采集按钮。
4. 在目标应用中点击需要采集的控件，DomScan 会显示辅助功能元数据。点选覆盖层拦截本次点击，不会执行控件原有操作。

有些应用没有实现辅助功能接口，或者只暴露一个整体容器；DomScan 无法从中恢复未提供的子控件，此时可改用区域截图。辅助功能采集只读取描述性属性，不读取控件的 `AXValue` 或选中文本。

## 框选截图

1. 选择目标应用，在 **“其他采集方式”** 中点击 **“框选截图区域”**。
2. 首次使用时，在 **系统设置 → 隐私与安全性 → 屏幕与系统音频录制** 中允许 DomScan（旧版 macOS 名为“屏幕录制”）。部分系统版本需要重新打开 DomScan，之后再次选择目标应用和采集方式。
3. 在目标窗口中拖动框选区域，松开鼠标完成采集。每次截图限定在起始目标窗口内，不包含其他应用窗口；最小区域为 4 × 4 逻辑点，PNG 最长边最多为 2048 像素。
4. 在详情区预览图像、填写备注，或点击 **“导出 PNG 图像”** 保存原图。

辅助功能和截图坐标均为**全局屏幕逻辑点，原点位于主屏幕左上角**，与 DOM 的 frame 内 CSS 像素坐标不同。位于主屏幕左侧的显示器可能出现负 X 坐标。

## 取消与数据保存

Esc、右键、“取消选择”以及切换到其他应用都会关闭选择层；30 秒未完成会自动取消。取消后恢复 DomScan 主窗口，不会留下阻挡输入的覆盖层。

三种来源都支持备注、按来源应用归档、复制及 Markdown / JSON 导出。JSON 在每项记录中包含 `source`，截图通过 `imagePNGBase64` 保留 PNG 数据；Markdown 导出及复制内容内嵌 PNG 数据 URI，预览区省略其编码文本。部分 Markdown 阅读器不支持数据 URI，遇到此情况可在详情区单独导出 PNG。

记录只保存在本次运行的内存中，退出前请导出需要保留的内容。截图包含框选区域内实际可见的信息，框选时请留意区域内容；原生控件采集不读取输入框当前值，区域截图则可能包含画面中可见的输入文字。
